Полевые игроки:
- база 5,2;
- гол +0,5; пас +0,3; автогол -1,0;
- результат команды: (победы - поражения) / сыгранные матчи * 1,8;
- коэффициенты формата: 2 команды +2,00; 3 команды +2,15; 4 команды +2,05;
- итоговая шкала сжимается относительно базы и ограничена 0–10.

Профильные вратари:
- база 6,8;
- сейв +0,025, суммарный бонус за сейвы ограничен +1,5 за игровой день;
- пропущенный гол -0,1;
- результат команды: (победы - поражения) / сыгранные матчи * 1,0;
- поправка формата: 2 команды 0; 3 команды +0,2; 4 команды +0,1;
- голы/пасы/автоголы по-прежнему учитываются по общим персональным правилам;
- сейвы и пропущенные учитываются только если игрок отмечен в воротах и у него установлен профиль вратаря.

Контрольный пример: профильный вратарь, формат 2 команды, поражение в единственном матче, 60 сейвов и 7 пропущенных:
6,8 + min(60*0,025, 1,5) - 7*0,1 - 1,0 = 6,6.
