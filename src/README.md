# Будничный футбол — UI V11

В V11 редактор игрового дня переведён из старого iframe-редактора в отдельный React-модал.

Что исправлено:
- список всех игроков в редакторе берётся из текущего состояния Supabase через основной интерфейс;
- мобильная версия редактора без горизонтального выхода за экран;
- сохранение даты, места, команд, матчей, состава, статистики и изображения;
- расчёт рейтинга дня использует существующую функцию рейтинга из рабочего модуля;
- старый рабочий модуль остаётся скрытым движком данных для совместимости с рейтингом и просмотром игрового дня.
