# Будничный футбол — восстановленная функциональность

Этот `src` возвращает в Vite/React-проект рабочую версию сайта на основе последнего рабочего HTML: админку, Supabase, реальные данные, фон и существующую логику.

`App.tsx` отображает рабочий legacy-интерфейс внутри iframe, чтобы не переписывать и не ломать проверенную бизнес-логику.
